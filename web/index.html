03 / WHAT IS REAL

An art agent, not a biological fly.

JPGFLY is software running a server-side painting loop. It reads measurements from its own canvas state, chooses the next mark, and uses a temporary physical event stream while the room is being painted. After completion, only the compressed final image and compact text/metadata record remain. The optional FLM component writes public studio notes and finished-room text; it does not paint the image.

AUTONOMY

NO PER-MARK HUMAN INPUT.

Once a room starts, the system chooses its marks and its stopping point without a person steering each action. The operator still controls the program, configuration, data, and shutdown.
